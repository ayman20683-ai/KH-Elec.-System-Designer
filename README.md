## 🌟 Overview
**KH Elec. System Designer** is a powerful automation tool designed to streamline the electrical design process for MEP engineers and BIM modelers. It eliminates manual calculations and ensures accuracy by integrating international standards and local supplier data directly into your workflow.

---

## ✨ Key Features
* **⚡ Elsewedy Electric Integration:** Direct access to the 2026 Elsewedy Cable Catalog with automatic Outside Diameter (OD) retrieval.
* **🤖 Smart Auto-Sizing:** Automatically selects the optimal size for Trays, Trunking, and Conduits based on the calculated Fill Ratio.
* **📏 Advanced Grouping Logic:** Support for **Touching** and **Spaced** formations with high precision.
* **🛠️ Multi-System Support:** Dedicated modules for:
    * **Cable Trays:** Dynamic width and depth calculations.
    * **Trunking:** Specialized 40% Fill Factor logic for LC and Signal systems.
    * **Conduits:** Standard trade size (Ø) selection.
* **📊 One-Click Export:** Generate professional Excel reports ready for technical submittals.

## 🚀 How to Install
1.  Go to the [Releases](https://github.com/ayman20683-ai) page.
2.  Download the latest `KH ELEC. SYSTEM DESIGNER V2.0.rar`.
3.  Extract the folder and run `KH ELEC. SYSTEM DESIGNER V2.0.exe`.

## 📖 How to Use
1.  **Select Tab:** Choose between General, Elsewedy, 
2.  **Input Data:** Enter cable diameters, quantities, and grouping factors.
3.  **Mode Selection:** Toggle between **AUTO** for smart sizing or **MANUAL** for custom control.
